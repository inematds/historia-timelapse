A city's history, growing on the map

From the first settlement to today: the city is born and grows in 3D, with the year, population, the flag of each era and cards with sources. No video AI and no render cost.

In short

historia-timelapse is a set of scripts that turns a city's history into a 3D video, as a timelapse. It uses the real terrain relief and the OpenStreetMap buildings: each building "is born" in the year its neighborhood was settled, and the city grows on screen along with the IBGE population counter. Events appear on cards with a number, an explanation and a source. To use it, you need a computer with a graphics card, Python and Node, and some historical research on the city.

What it is

A history engine on a 3D map

Real data instead of invented images.

🏙️ The city is born year by year

30 m Copernicus terrain and OpenStreetMap buildings (with Microsoft's open dataset where OSM has little). Each building gets a year from its neighborhood and the population curve.

📜 Cards with sources

Each event has a title, a big number, an explanation and a source. The year, population (IBGE censuses) and the flag of the regime change in the corner of the screen.

🎬 History effects

A globe zooming in to the city, a timeline, fleets sailing, sieges, fortresses, bridges being drawn, landfills growing in color and floods rising.

How it works

From data to video

Everything runs on your machine: deck.gl in Chrome with the GPU, about 0.1 s per frame at 1080p.

Historical research→ OSM + terrain→ Year of each building→ Script (blocks)→ Scene→ Render + soundtrack
Prerequisites

What you need

Linux with a graphics card, Python 3 and Node 20+. The data are public files.

Python

To cut out the map and prepare the data.

python3 -m venv .venv
.venv/bin/pip install osmium tifffile imagecodecs shapely numpy pyproj scipy pillow

Node + Chrome

The render uses Playwright with Chromium.

cd motor && npm i
npx playwright install chromium

Public data

A regional OSM extract (Geofabrik) and Copernicus GLO-30 terrain tiles in dl/.

# example: Southern Brazil + 1 terrain tile
https://download.geofabrik.de/south-america/brazil/sul-latest.osm.pbf
https://copernicus-dem-30m.s3.amazonaws.com/
User guide · step by step

Make the video of your city

Each city lives in cidades/<id>/. The scripts read the city from the CIDADE variable.

1

Create the city configuration

The map bounding box (west, south, east, north), the municipality name in OSM and the point where the city began.

# cidades/floripa/config.json
{ "nome": "Florianópolis", "bbox": [-48.80, -27.92, -48.33, -27.33],
  "pbf": "dl/sul.osm.pbf", "municipio_osm": "Florianópolis",
  "centro_antigo": [-48.5490, -27.5965] }
2

Do the historical research

In cidades/<id>/dados/pesquisa/: populacao.json (censuses and estimates), eventos.json (events with a source and coordinates) and bairros_epocas.json (the settlement year of each neighborhood). Use the Porto Alegre and Florianópolis ones as a model.

ls cidades/floripa/dados/pesquisa/   # population, events, neighborhood eras, regimes, images, RESUMO.md
3

Cut out the map and prepare the data

Buildings, water, neighborhoods, terrain with the sea, the birth year of each building and effects (bridges, forts, landfills).

export CIDADE=floripa
.venv/bin/python -I scripts/extrai_osm.py dl/sul.osm.pbf cidades/floripa/dados/brutos
.venv/bin/python -I scripts/extrai_msbuild.py   # optional: Microsoft buildings where OSM is sparse
.venv/bin/python -I scripts/prep_terreno.py
.venv/bin/python -I scripts/prep_predios.py
.venv/bin/python -I scripts/modelo_anos.py
.venv/bin/python -I scripts/extrai_feicoes.py && .venv/bin/python -I scripts/prep_efeitos.py
4

Write the script and generate the scene

The script is a list of blocks: years, camera, card and effects. For Florianópolis it is built by roteiro_floripa.py from the research.

python3 cidades/floripa/roteiro_floripa.py
.venv/bin/python -I scripts/gerar_cena.py   # cidades/floripa/cena/cena.js
5

Check frames before rendering

Render just a few seconds to check the framing, cards and effects.

cd motor && node render.mjs ../cidades/floripa/cena --quadros 20,60,120   # q_*.jpg in the scene folder
6

Render and add the soundtrack

Without narration: looped music with a transition. With narration: see cidades/poa/narracao/.

node render.mjs ../cidades/floripa/cena ../cidades/floripa/final/video.mp4
CIDADE=floripa ../.venv/bin/python -I ../scripts/montar_musica.py
ffmpeg -i ../cidades/floripa/final/video.mp4 -i ../cidades/floripa/final/audio.wav -map 0:v -map 1:a -c:v copy -c:a aac -shortest final.mp4
